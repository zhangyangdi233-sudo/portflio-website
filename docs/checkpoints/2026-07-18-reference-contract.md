# Reference translation contract

## Mechanisms retained

- The Art of Cinema: monumental typography, duplicated glyphs in clipped masks, chapter changes tied to scroll, restrained image fields.
- ZUTOMAYO and the supplied reference image: overlapping window hierarchy, unmistakable title bars, close/minimize controls, focus order, direct dragging.
- Rams / International Style / Bauhaus / Constructivism: legible evidence hierarchy, asymmetric grid, honest controls, sparse rules and labels.

## Surfaces excluded

- No copied HTML, CSS, JavaScript, assets, fonts, copy, exact geometry, title sequence, logos, characters, or reference screenshots.
- No purple Windows surface from the supplied image; the original CIBA interface remains black, warm paper, and acid green.
- No decorative control may imply an interaction that does not work.

## Acceptance boundary

- Home narrative mode: cinematic. Its only anomaly is the clipped letter roll.
- Works narrative mode: spatial. Its only anomaly is movable project windows.
- Mobile and reduced motion use ordered reading with no focusable drag handle.
- Public pages contain only verified project records; draft placeholders stay editable but unpublished.
