# Page topology

## Home

1. Fixed utility navigation: Portfolio, CIBA, and language links.
2. Pinned cinematic stage: one active project title, summary and moving media field.
3. Artist statement bridge: ends the pinned sequence and returns to document flow.
4. Extracted works stack: project files pull apart through scroll.
5. Minimal ordered index: reliable scan and deep-link fallback.
6. Footer/contact.

Interaction model: scroll-driven for the cinematic stage and file stack; click-driven only for navigation. The home page must not require dragging.

## Works

1. Standard site header.
2. Compact editorial introduction: Works title, one-sentence purpose and interaction hint.
3. Workspace toolbar: All / Featured / Archive, Scatter / Scan, Reset layout, live status.
4. Project workspace:
   - Desktop: absolutely positioned project windows inside a bounded grid field.
   - Mobile and Scan mode: ordered project list using the same window component.
5. Project dock: one restore/focus button per project with closed/visible state.
6. Footer/contact.

Interaction model: drag + click + keyboard on desktop; ordered click navigation on mobile. Every project remains reachable by a normal anchor URL.

## Project detail

1. Header.
2. Project title and metadata.
3. Primary media.
4. Localized body and production context.
5. External play/archive actions.
6. Next project and footer.

The project pages remain deliberately calmer than the home and Works workspace so professors can evaluate the work without decorative interference.
