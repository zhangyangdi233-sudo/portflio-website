# Page topology

## Home

1. Black utility navigation: CIBA, Works, About, Contact, and three language links.
2. Monumental CIBA opening with one compact media line and one Works action.
3. Pinned cinematic stage: one active project title, concept, and low-opacity draggable image field.
4. Scroll triggers change the current title and evidence set.
5. Minimal ordered index: reliable scan and deep-link fallback.
6. Footer/contact.

Interaction model: scroll changes the active work; desktop fine-pointer users may rearrange images,
but every project remains readable and linked without dragging. Mobile and reduced motion use a
linear sequence.

## Works

1. Standard site header.
2. Compact editorial introduction: Works title, one-sentence purpose and interaction hint.
3. Workspace toolbar: All / Featured / Archive, Windows / Order, Reset layout, live status.
4. Project workspace:
   - Desktop: absolutely positioned project windows inside a bounded grid field.
   - Mobile, Order, and reduced-motion modes: ordered project list using the same window component.
5. Project dock: one restore/focus button per project with closed/visible state.
6. Footer/contact.

Interaction model: drag + click + keyboard on desktop; ordered click navigation on mobile. Every project remains reachable by a normal anchor URL.

## Project detail

1. Header.
2. Project title and metadata.
3. Primary media.
4. Localized body and production context.
5. External play/archive actions.
6. Next project and footer.

The project pages remain deliberately calmer than the home and Works workspace so professors can evaluate the work without decorative interference.
