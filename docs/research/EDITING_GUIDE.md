# Editing guide

The website is the executable source of truth. The bundled Figma plugin is an editable visual handoff generated from the same design direction; it is not required to publish the site.

For the shortest Codex/Figma workflow, start with `../CIBA_STYLE_WORKSPACE.md`.

## Edit content without touching layout code

- Artist name, statement, CV, optional email/CV download, location, and social links: `src/content/site/profile.json`
- One JSON file per work: `src/content/projects/*.json`
- Palette, type stacks, motion timing, workspace height, and every window's x/y/width/rotation/z: `src/content/art-direction.json`
- Project media files: `public/assets/projects/<slug>/`; reference them with
  `/assets/projects/<slug>/...` paths in project JSON. A single SVG may instead live at
  `public/assets/projects/<slug>.svg` while a project is awaiting final documentation.

Every project needs at least one media item and one body paragraph in Chinese, English, and Japanese. The site builds all three language routes from those files.

## Add a project

1. Duplicate one project JSON file and choose a unique `slug`.
2. Fill year, medium, status, priority, featured state, tags, palette, media, optional links, and all three translations. For professor-facing records, also add the optional `details` fields: role, scale, duration, platform, and credits.
3. Add a position with the same slug under `workspace.positions` in `src/content/art-direction.json`. If omitted, the site supplies a safe fallback position.
4. Run `npm run check:design`, `npm run check`, `npm test`, and `npm run build`.

The standard detail page renders the first media item as the hero and all remaining items as a gallery. `play` and `archive` links are both supported.

## Change visual direction

Edit `src/content/art-direction.json` first. CSS variables are generated by `src/lib/art-direction.ts` and applied globally. Structural design rules live in `skills/ciba-art-direction/references/aesthetic-system.md`; explicit feedback can be appended with the skill's `scripts/add_taste_observation.py`.

## Editable Figma handoff

Follow `figma-export/README.md` to import the local plugin. It generates editable text, shapes, media placeholders, design tokens, and seven independent Works windows. Website interactions such as real drag bounds, filtering, routing, and reduced-motion behavior remain in code.

## Local preview

```bash
npm install
npm run dev
```

Append `?motion=reduce` to any local route to preview the same static composition used for the
OS-level reduced-motion path, for example `http://localhost:4321/zh/?motion=reduce`.

Before publishing:

```bash
npm run check
npm test
npm run build
```

Add the real email, CV download, playable-build URL, role/scale/credits facts, and final artwork media before presenting the portfolio. Optional links stay hidden until supplied, so unfinished placeholders never produce broken public actions.
